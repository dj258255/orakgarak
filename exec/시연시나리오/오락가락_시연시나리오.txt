오락가락 서비스 시연 시나리오

1. 서비스 접속 및 로그인 -> 브라우저에서 j13c103.p.ssafy.io 접속
1.1 웹사이트 접속 -> 랜딩페이지 로딩 확인
1.2 로그인 진행 -> 랜딩페이지에서 서비스명 아래 "Enter" 버튼 클릭
1.2.1. 구글 로그인 팝업창 확인
1.2.2. 구글 계정으로 로그인 완료


2. 피드 탐색 및 소셜 기능
2.1 피드 페이지 진입
2.1.1. 상단 헤더의 "피드" 버튼 클릭
2.1.2. 메인 피드 페이지 로딩 (인스타그램 스타일)

2.2. 피드 상호작용
2.2.1. 피드에 올라온 앨범 중 하나 선택
2.2.2. 앨범 상세페이지 진입
2.2.3. 음악 재생 버튼 클릭하여 노래 듣기
2.2.4. 댓글 입력창에 댓글 작성 후 등록
2.2.5. 좋아요 버튼 클릭
2.2.6. 해당 사용자 프로필에서 팔로우 버튼 클릭

2.3. 팔로잉 페이지 확인
2.3.1. 상단 헤더의 "팔로잉" 버튼 클릭
2.3.2. 팔로우한 사용자들의 피드 확인


3. 음역대 체크 게임
3.1. "목소리 풀기 게임" 버튼 클릭
3.2. 음역대 체크 게임 진행
3.3. 게임 완료 후 결과 확인

4. 추천 시스템 체험
4.1 추천 페이지 접속
4.1.1. 상단 헤더의 "추천" 버튼 클릭

4.2. 노래 추천 받기
4.2.1. "노래 추천받기" 버튼 클릭
4.2.2. 추천된 노래 목록 확인

4.3. 추천 시스템 피드백
4.3.1. 마음에 들지 않는 노래에 "싫어요" 버튼 클릭
4.3.2. "다시 추천받기" 버튼 클릭
4.3.3. 업데이트된 추천 목록 확인

4.4. 유사 음성 기반 추천
4.4.1. "내 목소리와 비슷한 사람이 많이 부른 노래" 메뉴 클릭
4.4.2. 추천 노래 목록 확인 


5. 노래 예약 및 녹음
5.1. 노래 예약하기
5.1.1. 추천받은 노래 중 하나 선택
5.1.2. "노래 예약하기" 버튼 클릭
5.1.3. 예약 목록에 추가 확인

5.2. 녹음 페이지 이동
5.2.1. "노래 부르러 가기" 버튼 클릭
5.2.2. 녹음 페이지 진입

5.3. 노래 선택 및 순서 조정
5.3.1. 예약된 노래 목록 확인
5.3.2. 검색창에서 추가할 노래 검색
5.3.3. 검색된 노래를 드래그앤드롭으로 순서 변경

5.4. 녹음 진행
5.4.1. 첫 번째 노래 "시작" 버튼 클릭
5.4.2. 노래 반주에 맞춰 노래 부르기 시연
5.4.3. 노래 완료 후 "녹음 저장" 버튼 클릭

5.5. 녹음 파일 관리
5.5.1. 녹음된 파일 미리듣기 재생
5.5.2. 녹음 제목 입력창에 제목 입력
5.5.3. "저장" 버튼 클릭하여 최종 저장

6. 파일 업로드 및 앨범 제작
6.1. 외부 파일 업로드
6.1.1. "파일 업로드" 버튼 클릭
6.1.2. 로컬에서 음성 파일 선택하여 업로드
6.1.3. 업로드 완료 확인

6.2. 앨범 만들기
6.2.1. 마이페이지의 "앨범 만들기" 버튼 클릭
6.2.2. 녹음된 파일들 중 선택하여 앨범 구성
6.2.3. 앨범 커버를 업로드하거나 AI로 앨범커버 생성
6.2.4. 앨범 제목 및 설명 입력
6.2.5. "앨범 생성" 버튼 클릭


7. 마이페이지 관리
7.1 마이페이지 접속
7.1.1. 상단 헤더의 프로필 아이콘 클릭
7.1.2. 마이페이지 진입
7.2. 내 녹음 파일 관리
7.2.1. "내 녹음" 탭 클릭
7.2.2. 녹음된 파일들 목록 확인
7.2.3. 파일 중 하나 선택하여 재생

7.3 피드 작성
7.3.1. 생성한 앨범을 선택
7.3.2. "피드 작성" 버튼 클릭
7.3.3. 피드 내용 작성 후 "게시" 버튼 클릭

8. AI 데모 체험
8.1. AI 데모 신청
8.1.1 "AI 데모" 메뉴 클릭

8.2. AI 분석 결과 확인
8.2.2. "결과 듣기" 버튼 클릭

9. 시연 완료
9.1. 전체 시연을 통해 오락가락 서비스의 핵심 기능인 음성 기반 소셜 네트워킹, AI 추천 시스템, 녹음 및 공유 기능을 모두 체험하였습니다.
