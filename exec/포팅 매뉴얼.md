# 포팅 매뉴얼 (Porting Manual)

## 1. 개발 환경

#### Backend 환경
- **Java**: OpenJDK 17
- **Spring Boot**: 3.5.5
- **Build Tool**: Gradle 8.x
- **WAS**: Spring Boot 내장 Tomcat
- **IDE**: IntelliJ IDEA

#### Frontend 환경
- **Node.js**: 18.x 이상
- **React**: 18.x
- **TypeScript**: 5.x
- **Build Tool**: Vite
- **Package Manager**: npm
- **IDE**: VS Code

#### Python 환경
- **Python**: 3.10
- **Framework**: FastAPI
- **IDE**: VS Code

#### Database 환경
- **MySQL**: 8.0
- **Redis**: 7.x

#### 배포 환경
- **OS**: Ubuntu 20.04 LTS
- **Docker**: 20.10.x
- **Docker Compose**: 2.x

### 빌드 시 사용되는 환경 변수 등의 내용 상세 기재

#### Backend 환경 변수 (.env 파일)
```bash
# Database Configuration
DB_USERNAME=your_db_username
DB_PASSWORD=your_db_password
DB_NAME=your_db_name
DB_PORT=3306

# Redis Configuration
REDIS_PASSWORD=your_redis_password
REDIS_PORT=6379

# JWT Configuration
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRATION=86400

# Google OAuth2
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# AWS S3 Configuration
AWS_ACCESS_KEY=your_aws_access_key
AWS_SECRET_KEY=your_aws_secret_key
AWS_REGION=ap-northeast-2
AWS_S3_BUCKET=your_s3_bucket_name

# Server Configuration
SERVER_PORT=8080
SPRING_PROFILES_ACTIVE=prod
```

#### Frontend 환경 변수 (.env 파일)
```bash
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

#### Python 환경 변수
```bash
# AI Service Configuration
AI_SERVICE_PORT=8000
MODEL_PATH=/app/models
AUDIO_TEMP_DIR=/tmp/audio

# Database Connection (if needed)
DATABASE_URL=mysql://username:password@localhost:3306/karaoke_db
REDIS_URL=redis://localhost:6379
```

### 배포 시 특이사항 기재

#### Docker 배포
- `docker-compose.yml` 파일을 통한 통합 배포
- MySQL, Redis, Backend,Python 서비스 일괄 관리
- 네트워크 설정을 통한 서비스 간 통신 구성

#### 파일 저장소 설정
- AWS S3 버킷 생성 및 권한 설정 
- CORS 정책 설정

#### Jenkins 배포 자동화
```
        pipeline {
            agent any
        
            stages {
                stage('Checkout') {
                    steps {
                        echo 'Cloning Repository'
                        git branch: 'master',
                            url: 'https://lab.ssafy.com/s13-bigdata-recom-sub1/S13P21C103.git',
                            credentialsId: 'sjwToken'
                    }
                }
                stage('Build Frontend') {
                    steps {
                        echo 'Building Frontend Application'
                        nodejs(nodeJSInstallationName: 'node') {
                            dir('front') {
                                withCredentials([file(credentialsId: 'frontenv', variable: 'FRONT_ENV_FILE')]) {
                                    sh '''
                                        set -eu
                                        
                                        echo "Injecting frontend env file"
                                        cp "$FRONT_ENV_FILE" .env
                                        chmod 600 .env
                                        cat .env
                                        echo "Node version: $(node --version)"
                                        echo "NPM version: $(npm --version)"
                
                                        # 의존성 설치
                                        npm ci
                
                                        # 프로덕션 빌드
                                        npm run build
                                    '''
                                }
                            }
                        }
                    }
                }
                
                stage('Deploy Frontend') {
                    steps {
                        echo 'Deploying Frontend to Nginx'
                        dir('front') {
                            sh '''
                                set -eu
                
                                BUILD_DIR=""
                                if [ -d dist ]; then
                                    BUILD_DIR="dist"
                                elif [ -d build ]; then
                                    BUILD_DIR="build"
                                else
                                    echo "Error: Build directory not found"
                                    exit 1
                                fi
                
                                echo "Deploying from $BUILD_DIR"
                
                                # 기존 html 삭제 후 복사
                                sudo rm -rf /var/www/html/*
                                sudo cp -r $BUILD_DIR/* /var/www/html/
                
                                # 권한 설정
                                sudo chown -R www-data:www-data /var/www/html/
                                sudo chmod -R 755 /var/www/html/
                
                                # nginx 재시작
                                sudo systemctl reload nginx
                            '''
                        }
                    }
                }
                stage('Deploy') {
                    steps {
                        echo 'Deploy with Docker Compose'
                         dir('back') {
                              withCredentials([file(credentialsId: 'backendEnv', variable: 'ENV_FILE')]) {
                                sh '''
                                     set -eu                                                                                                                                                               
                  
                                     # .env 파일 먼저 복사                                                                                                                                                 
                                     cp "$ENV_FILE" .env                                                                                                                                                   
                                     chmod 600 .env                                                                                                                                                        
                                     cat .env
                                     # 환경변수 추출 (더 안전한 방법)                                                                                                                                      
                                     NGINX_BASIC_AUTH_USER=$(grep "^NGINX_BASIC_AUTH_USER=" .env | cut -d'=' -f2- | tr -d '"' | tr -d "'" | xargs)
                                     NGINX_BASIC_AUTH_PASSWORD=$(grep "^NGINX_BASIC_AUTH_PASSWORD=" .env | cut -d'=' -f2- | tr -d '"' | tr -d "'" | xargs)                                                        
                
                                     # 환경변수가 제대로 추출되었는지 확인                                                                                                                                 
                                     echo "User: [$NGINX_BASIC_AUTH_USER]"                                                                                                                                 
                                     echo "Password length: ${#NGINX_BASIC_AUTH_PASSWORD}"                                                                                                                 
                
                                     # 환경변수가 비어있는지 확인                                                                                                                                          
                                     if [ -z "$NGINX_BASIC_AUTH_USER" ] || [ -z "$NGINX_BASIC_AUTH_PASSWORD" ]; then                                                                                       
                                         echo "Error: Environment variables are empty"                                                                                                                     
                                         echo "Checking .env file content:"                                                                                                                                
                                         grep "NGINX_BASIC_AUTH" .env || echo "No NGINX_BASIC_AUTH variables found"                                                                                        
                                         exit 1                                                                                                                                                            
                                     fi                                                                                                                                                                    
                
                                     # htpasswd 파일 생성                                                                                                                                                  
                                     rm -f .htpasswd                                                                                                                                                       
                                     htpasswd -cb .htpasswd "$NGINX_BASIC_AUTH_USER" "$NGINX_BASIC_AUTH_PASSWORD"                                                                                          
                
                                     # 파일 내용 확인                                                                                                                                                      
                                     echo "Generated .htpasswd content:"                                                                                                                                   
                                     cat .htpasswd                                                                                                                                                         
                
                                     # Nginx가 참조할 수 있도록 /etc/nginx/로 복사                                                                                                                         
                
                                     sudo cp .htpasswd /etc/nginx/.htpasswd                                                                                                                                
                
                                     sudo chmod 644 /etc/nginx/.htpasswd                                                                                                                                   
                
                                     # 복사된 파일 확인                                                                                                                                                    
                                     echo "Copied .htpasswd content:"                                                                                                                                      
                                     sudo cat /etc/nginx/.htpasswd                                                                                                                                         
                
                                     sudo mkdir -p /var/log/app
                                     sudo chown -R 1000:1000 /var/log/app  # appuser의 UID:GID
                                     sudo chmod 755 /var/log/app
                                        
                                     # Docker Compose 실행                                                                                                                                                 
                                     docker-compose down --remove-orphans || true                                                                                                                          
                                     docker-compose up -d --build  
                                     
                                '''
                              }
                         }
                    }
                }
                
                stage('Deploy Data') {
                    steps {
                        echo 'Deploy Data with Docker Compose'
                        dir('python') {
                            withCredentials([file(credentialsId: 'dataEnv', variable: 'DATA_ENV_FILE')]) {
                                sh '''
                                    set -eu
                                    cp "$DATA_ENV_FILE" .env
                                    chmod 600 .env
                                    docker-compose down || true
                                    docker-compose up -d --build
                                '''
                            }
                        }
                    }
                }
                
            }
        
            post {
                success {
                    script {
                        def Author_ID = sh(script: "git show -s --pretty=%an", returnStdout: true).trim()
                        def Author_Name = sh(script: "git show -s --pretty=%ae", returnStdout: true).trim()
                        mattermostSend(
                            color: 'good',
                            message: "빌드 성공: ${env.JOB_NAME} #${env.BUILD_NUMBER} by ${Author_ID}(${Author_Name})\nDetails: ${env.BUILD_URL}",
                            endpoint: 'https://meeting.ssafy.com/hooks/o6hxsm8outyc5cjtmed87wssxh',
                            channel: 'C103Jenkins'
                        )
                    }
                }
        
                failure {
                    script {
                        def Author_ID = sh(script: "git show -s --pretty=%an", returnStdout: true).trim()
                        def Author_Name = sh(script: "git show -s --pretty=%ae", returnStdout: true).trim()
                        mattermostSend(
                            color: 'danger',
                            message: "빌드 실패: ${env.JOB_NAME} #${env.BUILD_NUMBER} by ${Author_ID}(${Author_Name})\nDetails: ${env.BUILD_URL}",
                            endpoint: 'https://meeting.ssafy.com/hooks/o6hxsm8outyc5cjtmed87wssxh',
                            channel: 'C103Jenkins'
                        )
                    }
                }
            }
        }
```
