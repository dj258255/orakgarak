# 외부 서비스 정보

## 프로젝트에서 사용하는 외부 서비스 목록

### 1. Spotify Client API

**용도:**
- 음악 데이터 검색 및 메타데이터 수집
- 노래 정보(제목, 아티스트, 앨범, 장르) 조회

**참고문서:**
- [Spotify Web API Documentation](https://developer.spotify.com/documentation/web-api/)
- [Spotify API Reference](https://developer.spotify.com/documentation/web-api/reference/)
- [Client Credentials Flow](https://developer.spotify.com/documentation/general/guides/authorization/client-credentials/)

**적용기능:**
- 노래 데이터베이스 구축
- 추천 시스템을 위한 음악 메타데이터 수집

---

### 2. Google OAuth 2.0

**용도:**
- 사용자 인증 및 로그인 처리
- 소셜 로그인을 통한 간편한 회원가입
- 사용자 프로필 정보 조회

**참고문서:**
- [Google OAuth 2.0 Documentation](https://developers.google.com/identity/protocols/oauth2)
- [Google Sign-In for Web](https://developers.google.com/identity/sign-in/web)
- [OAuth 2.0 Scopes for Google APIs](https://developers.google.com/identity/protocols/oauth2/scopes)

**적용기능:**
- Google 계정을 통한 원클릭 로그인
- JWT 토큰 기반 사용자 세션 관리
- 사용자 기본 프로필 정보 자동 수집
- 보안성 강화된 인증 시스템 구현

---

### 3. Pinecone Vector Database

**용도:**
- 음성 특성 벡터 저장 및 유사도 검색
- AI 음성 분석 결과 데이터 관리
- 사용자별 음성 패턴 학습 데이터 저장

**참고문서:**
- [Pinecone Documentation](https://docs.pinecone.io/)
- [Pinecone Python Client](https://docs.pinecone.io/docs/python-client)
- [Vector Search Guide](https://docs.pinecone.io/docs/vector-search)

**적용기능:**
- 사용자 음성 특성 벡터화 및 저장
- 유사한 음성 패턴을 가진 사용자 검색
- AI 기반 음성 분석 및 평가 시스템
- 개인화된 음성 코칭 추천 시스템

---

### 4. Amazon S3 (Simple Storage Service)

**용도:**
- 음성 녹음 파일 저장 및 관리
- 사용자 프로필 이미지 저장
- 정적 리소스 및 미디어 파일 호스팅

**참고문서:**
- [Amazon S3 Documentation](https://docs.aws.amazon.com/s3/)
- [AWS SDK for Java Documentation](https://docs.aws.amazon.com/sdk-for-java/)
- [S3 CORS Configuration](https://docs.aws.amazon.com/s3/latest/userguide/cors.html)

**적용기능:**
- 사용자 녹음 파일 업로드/다운로드
- 이미지 업로드 및 관리
---

## 환경 설정 요구사항

### Spotify Client API 설정
```bash
SPOTIFY_CLIENT_ID=your_spotify_client_id
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret
```

### Google OAuth 2.0 설정
```bash
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_REDIRECT_URI=http://localhost:3000/auth/callback
```

### Pinecone 설정
```bash
PINECONE_API_KEY=your_pinecone_api_key
PINECONE_ENVIRONMENT=your_pinecone_environment
PINECONE_INDEX_NAME=karaoke-voice-vectors
```

### Amazon S3 설정
```bash
AWS_ACCESS_KEY_ID=your_aws_access_key
AWS_SECRET_ACCESS_KEY=your_aws_secret_key
AWS_REGION=ap-northeast-2
AWS_S3_BUCKET_NAME=your_s3_bucket_name
```
